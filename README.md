# Smart Hospital Queue & Patient Management

A console-based hospital management system written in C.

## Tech
- Language: C (GCC / MinGW)
- Storage: binary files (.dat)
- Data structures: linked list, queue (in progress)

## Build & Run
```
mingw32-make
.\hospital.exe
```
